# Sunlit Verify for desktop — releases

Installers and update manifests for the desktop collector app. The source
lives in [sunlitbytes/sunlit-provenance](https://github.com/sunlitbytes/sunlit-provenance)
under `apps/verify-desktop`; its `desktop-v*` tags publish here.

The app's built-in updater reads `latest-mac.yml` / `latest.yml` from the
latest release, so this repository stays public and holds nothing but
releases.
